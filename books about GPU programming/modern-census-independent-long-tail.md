# Independent and long-tail GPU-programming books, 2016-present

Observed and checked: 2026-09-23.

This file is part of the [2016-present census](modern-census-2016-present.md).
It exists because publisher-only searching misses a surprising amount of the
GPU-programming book market.

There is **no quality threshold** here. A title belongs when it is a real,
identifiable English-language book or completed digital book whose central
subject is programming a GPU or a GPU-facing programming interface. A bad,
obscure, self-published book is still evidence that a book exists.

Format variants are not separate books. Substantially revised editions are.

## Deliberately separate from the main count

Very short books such as an "API in 20 Minutes" title are recorded here because
they are sold/cataloged as books, but should not silently inflate counts of
full-length textbooks.

Likewise, unfinished Leanpub manuscripts are not counted as published books.
Completed Leanpub books are counted because the digital publication itself is
the released artifact.
