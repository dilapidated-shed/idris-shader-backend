## Why it belongs here

The book is shader-centered rather than CUDA-centered. Its public description
covers the graphics pipeline and vertex, tessellation, geometry, and fragment
shader programming in GLSL.

For this backend that is useful as a broad comparison point: fragment shaders
are not an isolated arithmetic language. They live inside a staged pipeline
with interfaces, interpolation, and host-provided state. Examples that make
those boundaries explicit are useful when deciding what belongs in source
semantics, backend IR, generated GLSL, or the host renderer.
