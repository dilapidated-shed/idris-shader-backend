## Rights status

These books are not mirrored here.

The Real-Time Rendering resource page reports that several early *ShaderX*
volumes were made available as free downloads by arrangement with the
editor/publisher. That is valuable legitimate access, but "free download" is
not the same thing as a license allowing us to republish the PDFs. Copyright
notices in the books remain restrictive.

Likewise, publisher pages expose downloadable companion/source material for
parts of the series, but each source bundle or file needs its own license check
before redistribution.

## Why it belongs here

This series is a large historical record of practical GPU/shader techniques.
For this repository, it is most useful selectively rather than cover-to-cover:

- shader control-flow and data-layout tricks from constrained hardware eras;
- GPGPU articles that predate or sit alongside CUDA;
- filtering and image-space computation;
- ray traversal and spatial data structures;
- GPU mathematical/numerical methods;
- mobile/handheld GPU constraints.

The *GPU PRO 360 Guide to GPGPU* is a convenient GPGPU-focused cross-section of
material collected from the larger *GPU Pro* series.

## Source-code collections

There are public GitHub collections containing ShaderX/GPU Pro companion code.
Do not infer that an aggregator's top-level license relicenses every third-party
file it collected. Prefer the publisher/author source plus the individual
file/package license when deciding whether to vendor code.
