## Why it belongs here

This is the most directly numerical item in the catalog. Public chapter
metadata shows material on:

- dense linear algebra;
- tridiagonal systems;
- batched matrix exponentiation;
- GPU LU and QR work;
- small batched linear systems;
- sparse matrix-vector products;
- ordinary differential equations and related numerical kernels.

For this repository, the interesting question is not merely "can a GPU perform
the floating-point operations?" It is how a numerical algorithm is factored
into bounded kernels, memory layouts, reductions, and synchronization points
without destroying useful mathematical structure too early.
