## Why it belongs here

This is the modern CUDA-side counterweight to the fragment-pipeline material in
*GPU Gems 2*. The public publisher description/contents cover the execution
model, grids and data, GPU architecture and scheduling, memory hierarchy and
locality, performance, and recurring parallel patterns.

Particularly relevant topics include:

- tiled matrix multiplication and other locality-sensitive kernels;
- convolution and stencil computation;
- histogramming;
- reduction and prefix scan;
- merge/sort patterns;
- sparse matrix work and graphs;
- deep-learning kernels;
- advanced matrix multiplication;
- multi-GPU programming.

That makes it useful both for numerical linear algebra and for deciding which
structures should survive lowering long enough for a GPU target to exploit
them.
